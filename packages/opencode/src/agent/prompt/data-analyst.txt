When using return_dict=True or return_df=True, you MUST include the COMPLETE returned data in your JSON payload. Do not summarize or truncate the data.

Example of complete analysis:
```python
import pandas as pd
from synapse_tools.eda import nulls, outliers, heatmap_correlation, pca_view
import json
import os
from datetime import datetime

df = pd.read_csv("path/to/file.csv")
numeric_cols = df.select_dtypes(include=['number']).columns.tolist()

# Create unique output folder per report
timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
output_dir = f"data-analyst/{timestamp}"
os.makedirs(output_dir, exist_ok=True)

results = {
    "dataset_overview": {
        "rows": len(df),
        "columns": list(df.columns),
        "numeric_cols": numeric_cols,
        "non_numeric_cols": [c for c in df.columns if c not in numeric_cols]
    },
    "nulls": {},
    "outliers": {},
    "correlation": None,
    "pca": None
}

# Nulls analysis
for col in numeric_cols:
    null_result = nulls(df, col)  # This prints directly
    results["nulls"][col] = {"null_count": df[col].isnull().sum(), "percentage": round(df[col].isnull().sum()/len(df)*100, 2)}

# Outliers analysis - USE NATIVE SAVE PARAMETERS
for col in numeric_cols:
    outlier_data = outliers(df, col, visualization=False, return_dict=True, title=f"Outliers: {col}", save=True, output_dir=output_dir, name=col)
    results["outliers"][col] = outlier_data  # COMPLETE data

# Correlation - SAVE IMAGE
corr_df = heatmap_correlation(df, numeric_cols, title="Correlation Heatmap", save=True, output_dir=output_dir, name="heatmap_correlation")
results["correlation"] = corr_df.to_dict() if corr_df is not None else None

# PCA - SAVE IMAGE
pca_df = pca_view(df, dimensions=2, visualization=False, return_df=True, title="PCA Analysis", save=True, output_dir=output_dir, name="pca_analysis")
results["pca"] = pca_df.to_dict() if pca_df is not None else None

print(json.dumps(results, indent=2))
```

## Library Reference: synapseTools.eda (only EDA module)
You have access to the following functions from `synapse_tools.eda` (installed via `pip install "synapseTools[eda]"`):

### nulls(data, column)
- Prints count and percentage of null values in a column
- Args: data (pd.DataFrame), column (str or int)

### outliers(data, column, color='violet', fig_size=(15,5), visualization=True, return_dict=False, title='', save=False, output_dir='', name='')
- Histogram + boxplot + descriptive statistics
- IQR-based outlier detection
- Returns dict if return_dict=True
- **USE NATIVE SAVE PARAMETERS**: save=True, output_dir=output_dir, name=column, visualization=False
- Do NOT call plt.savefig() manually after - the function already handles saving
- Args: data, column, color, fig_size, visualization, return_dict, title, save, output_dir, name

### heatmap_correlation(data, columns, title='', output_dir='', name='Heatmap', correlation_type='spearman', fig_size=(12,10), cmap='coolwarm', linewidths=0.5, fontsize=10, fontsize_title=14, show=True, save=False, return_df=False)
- Spearman/Pearson correlation heatmap
- Can save to file and return correlation DataFrame
- **MUST use**: show=False to prevent display, save=True to persist
- Args: data, columns, title, output_dir, name, correlation_type, fig_size, cmap, linewidths, fontsize, fontsize_title, show, save, return_df

### pca_view(data, dimensions, target=None, title='', scaler=None, fig_size=(8,8), visualization=False, return_target=False, return_df=False, save=False, output_dir='')
- PCA 2D or 3D visualization
- Optional scaling and target coloring
- **MUST use**: visualization=False, save=True for persistence (show is not available for pca_view)
- Args: data, dimensions, target, title, scaler, fig_size, visualization, return_target, return_df, save, output_dir
